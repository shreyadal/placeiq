# PlaceIQ
adaptive AI interview coach for college placements. built from scratch.

- ml/: knowledge tracing with pykt (pip dependency). concepts = DSA, OS, DBMS, CN, OOP, ML
- backend/: fastapi
- frontend/: next.js, perception built directly on mediapipe face mesh
- rag/: company interview experiences + JDs + resume
- speech: whisper STT

rules: don't copy code from other repos. keep modules standalone. explain what you write.
